# Implementation Tech Plans

Implementation tech plans are detailed engineering design documents created only when work is imminent.

Roadmaps remain lightweight long-term backlogs. When an initiative from a roadmap's **Next** section is ready to begin, it should be promoted into `implementation/proposed/`.

## Lifecycle

- `proposed/`: Detailed implementation plan is being drafted or reviewed.
- `approved/`: Plan is approved and ready for Jira epic/story breakdown.
- `in-progress/`: Implementation has started.
- `complete/`: Feature is complete, merged, and considered finished.

## Pipeline

```text
💡 Idea
⬇️
🗺️ Roadmap
⬇️
📄 Implementation Tech Plan
⬇️
✅ Approval
⬇️
🎯 Jira Epic
⬇️
📝 Jira Stories
⬇️
💻 Implementation
⬇️
🔍 Review + CI
⬇️
🎉 Complete
```

Implementation plans should reference the relevant Level 1 foundation, Level 2 domain plan, and roadmap item.

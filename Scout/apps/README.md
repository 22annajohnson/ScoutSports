# Apps

This directory will contain Scout product applications.

## Directories

- `ios/` is the future home of the Scout iOS app. The current iOS project remains at the repository root until a dedicated migration plan is approved.
- `web/` is the future home of the Scout web application. The current web app lives in a separate repository and should not be moved here without an approved migration plan.

Application moves should be handled as explicit migration projects with technical plans, dependency mapping, CI updates, and reviewable Jira tickets.

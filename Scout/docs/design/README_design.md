# Design Documentation

This directory contains Scout design system and UX documentation.

Use this area to document visual language, component patterns, interaction principles, accessibility standards, and product-specific UX conventions.

## Documents

- `DESIGN_SYSTEM.md` defines the current design system starting point and product-level UX guidance.
- `DESIGN_FACTORY_ACCESS.md` defines internal employee-only access requirements for the Design Factory.
- `SCOUTDESIGN_USAGE_AUDIT.md` audits current iOS `ScoutDesign` adoption and migration gaps.
- `UI_PATTERN_INVENTORY.md` inventories duplicated or reusable-looking UI patterns for future design-system adoption work.

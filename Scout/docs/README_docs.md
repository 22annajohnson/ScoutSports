# Documentation

This directory contains durable Scout documentation used by product owners, engineers, reviewers, and AI agents.

Documentation should describe the intended product and technical system clearly enough that future implementation work can be planned and executed consistently.

## Directories

- `product/` contains product vision, feature scope, personas, and requirements.
- `architecture/` contains system architecture, boundaries, and technical direction.
- `design/` contains design system and UX documentation.
- `database/` contains data model, schema, and Supabase documentation.
- `agents/` contains instructions for AI planning and coding agents.
- `decisions/` contains architecture decision records and approved long-term decisions.

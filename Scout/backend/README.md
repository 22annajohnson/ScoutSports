# Backend

This directory contains backend-facing documentation and future backend assets for Scout.

Scout currently uses Supabase for authentication, data, and storage. Backend changes should be planned carefully because schema, storage, and auth decisions affect every product surface.

## Directories

- `supabase/` contains Supabase documentation and future SQL, migrations, Edge Functions, policies, and storage notes.

Schema, auth, storage, and public API changes require an approved technical plan before implementation.
